# E-Commerce Data Storytelling & Customer Segmentation

An exploratory data analysis, business intelligence, and customer segmentation project using transaction data, visual analytics, and K-Means clustering.

## Features

- **Business Intelligence Analytics:** Answers questions regarding category sales volume, geographical revenue distribution, payment method breakdowns, and seasonal trends.
- **Visual Analytics:** Generates multi-panel figures illustrating revenue by category, city-level performance, and payment distributions.
- **Customer Segmentation:** Applies RFM-style feature extraction, feature scaling, and K-Means clustering to identify customer archetypes.

## Project Structure

- `E_Commerce_Data_Storytelling.ipynb`: Main Jupyter Notebook with data processing, visualization, and clustering steps.
- `e_ticaret_veri_seti.csv`: E-commerce transaction dataset.
- `requirements.txt`: Python package requirements.
- `assets/`: Generated charts and figures.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alperencok/E-Commerce-Data-Storytelling.git
   cd E-Commerce-Data-Storytelling
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook:
   ```bash
   jupyter notebook E_Commerce_Data_Storytelling.ipynb
   ```
